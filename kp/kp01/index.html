BASIC CONCEPT

1. Definisi Komputer

Apakah itu komputer?

Komputer ialah mesin elektronik automatik yang menerima data dan arahan, memproses data mengikut arahan, menyimpan maklumat dan menghasilkan output yang berguna kepada pengguna.

⌨️

INPUT

Data dan arahan dimasukkan melalui peranti input.

⚙️

PROCESS

CPU memproses data berdasarkan arahan perisian.

🖥️

OUTPUT

Hasil pemprosesan dipaparkan kepada pengguna.

💾

STORAGE

Data disimpan untuk digunakan semula.

✅

COMPUTER SYSTEM

4. Komponen Sistem Komputer

🔩 Perkakasan

KEY POINTS

Point Penting

  • Komputer menerima input, memproses data, menghasilkan output dan menyimpan maklumat.
  • Komputer memerlukan perkakasan dan perisian untuk berfungsi.
  • Jenis komputer dipilih berdasarkan tujuan, prestasi, mobiliti dan lokasi penggunaan.
  • Sistem pengoperasian menjadi penghubung antara pengguna, aplikasi dan perkakasan.
